# BGP Labs — KG-Lab

Practical laboratories for studying and verifying BGP concepts
as part of CCNP ENCOR (350-401) preparation.

## Lab Index

| Lab | Topic | Status |
|-----|-------|--------|
| [Lab 01 — eBGP Basics](lab-01-ebgp-basics/README.md) | eBGP peering, IP addressing and route exchange | Available |
| Lab 02 — BGP Route Advertisement | Network advertisement and route verification | Planned |
| Lab 03 — BGP Neighbor Troubleshooting | Neighbor establishment and troubleshooting | Planned |
| Lab 04 — BGP Path Attributes | BGP attributes and their influence | Planned |
| Lab 05 — BGP Path Selection | Best-path selection and route comparison | Planned |

## Lab Environment

- Network emulator: GNS3
- Cisco router images: to be confirmed
- Configurations and verification results: documented for each lab
- Topology diagrams: Mermaid

## Lab Documentation Standards

Each lab should include:

1. Learning objectives
2. Prerequisites and lab environment
3. Mermaid topology diagram
4. IP addressing plan
5. Configuration steps
6. Verification commands and observed results
7. Troubleshooting notes
8. Screenshots where useful

## Important Notes

- Lab status must reflect actual progress and verification.
- Configurations and outputs must be validated in GNS3 before being
  presented as tested.
- Practice material is intended for learning and exam preparation.

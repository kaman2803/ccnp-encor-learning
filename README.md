# CCNP ENCOR Learning — KG-Lab

A module-based learning repository for CCNP ENCOR (350-401), with study notes in English, French explanations for difficult terms, self-written practice QCMs, flashcards, and practical labs.

## Learning website

The root `index.html` is the GitHub Pages dashboard. It links to the 24 module folders.

## Repository structure

```text
ccnp-encor-learning/
├── index.html                 # Learning dashboard
├── README.md                  # Project overview
├── assets/                    # Shared styles, scripts, and images
├── modules/
│   ├── module-01/
│   ├── module-02/
│   ├── ...
│   ├── module-11/             # Current focus: Exploring eBGP
│   └── ...
└── labs/                      # Cross-module practical labs
```

## Study method

1. Study the English notes.
2. Review difficult terms with French explanations.
3. Complete practice questions and read each explanation.
4. Review flashcards.
5. Perform the related lab and record verification results.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

Practice questions in this repository are learning exercises, not claimed official exam questions. Module titles will be aligned to the user's exact course syllabus as it is incorporated.


## Course outline

The dashboard follows the supplied 26-module course outline across six domains: Network Switching (1–7), Network Routing (8–13), Network Security (14–16), Virtualization and Network Services (17–20), Programmability (21–22), and Software-Defined Networking (23–26). It also lists six checkpoint exams, the end-of-course survey, and the final exam.

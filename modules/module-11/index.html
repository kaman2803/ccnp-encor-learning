1. Study Notes — in English

What is BGP?

Border Gateway Protocol (BGP) is a routing protocol used to exchange routing information between different Autonomous Systems (AS).

BGP is the main routing protocol used to exchange routes between networks on the Internet. It is also widely used in service provider networks and Multiprotocol Label Switching (MPLS) environments.

BGP is designed to support large networks and complex routing policies. It allows network administrators to control how traffic enters and leaves their networks.

Key characteristics of BGP

  • Interdomain routing: BGP exchanges routes between different Autonomous Systems.
  • Scalability: BGP can handle a very large number of routes, including Internet routing tables.
  • Policy-based routing: Administrators can influence route selection using BGP attributes and routing policies.
  • Reliability: BGP uses TCP to establish reliable connections between BGP neighbors.
  • Security: BGP supports mechanisms and operational practices that help protect routing information, although BGP is not automatically secure by default.

What is an Autonomous System (AS)?

An Autonomous System (AS) is a group of IP networks and routers managed by a single organization or under a common routing policy.

Each public AS is identified by an Autonomous System Number (ASN).

What are IGP, EGP, and BGP?

TermMeaningMain purpose
IGPInterior Gateway ProtocolExchanges routes within an AS. Examples: OSPF and EIGRP.
EGPExterior Gateway ProtocolGeneral category of protocols used for routing between ASes.
BGPBorder Gateway ProtocolThe principal interdomain routing protocol used on the Internet.
eBGPExternal BGPEstablishes BGP neighbor relationships between different ASes.
iBGPInternal BGPExchanges BGP routing information between peers in the same AS.
Important: BGP is used for both eBGP and iBGP. The distinction depends on whether the BGP peers belong to different ASes or the same AS.

Where is BGP used?

  1. Internet routing: Internet Service Providers (ISPs) exchange routes with other providers and networks.
  2. MPLS service provider networks: BGP supports services such as MPLS Layer 3 VPNs.
  3. Enterprise networks: Organizations use BGP for connections to multiple ISPs, data centers, and other external networks.

What will this module cover?

  • Interdomain routing with BGP.
  • BGP operations and neighbor relationships.
  • BGP path selection and path attributes.
  • Configuration and verification of a single-homed eBGP connection between a customer and a provider.

A single-homed connection means that a customer connects to one service provider through one external connection for that particular Internet access arrangement.

Quick Revision — Key Takeaways

  • BGP stands for Border Gateway Protocol.
  • BGP exchanges routing information between Autonomous Systems.
  • An AS is a group of networks managed under a common routing policy.
  • eBGP operates between different ASes.
  • iBGP operates between peers in the same AS.
  • BGP uses TCP port 179.
  • OSPF and EIGRP are examples of IGPs.
  • BGP is widely used for Internet routing and supports MPLS service provider environments.
  • A single-homed customer connects to one service provider in the scenario studied.

1. Study Notes — in English

11.2.0 Introduction

Border Gateway Protocol (BGP) exchanges network reachability information between Autonomous Systems (ASes). An AS groups networks under a common administrative and routing-policy framework. BGP allows each AS to apply policy to the routes it accepts and advertises.

Core idea: BGP is not simply trying to find the path with the lowest metric. It exchanges reachability information and supports policy-driven path selection between independently administered networks.

11.2.1 BGP Characteristics

  • TCP port 179: BGP peers establish a reliable, connection-oriented TCP session.
  • Incremental updates: after the initial exchange of routing information, BGP generally sends updates when reachability information changes rather than periodically resending the complete table.
  • Keepalives: BGP messages help maintain the peer relationship and detect when a peer is no longer responding.
  • Reliable transport: TCP provides sequencing, acknowledgements, retransmission, and flow control.
  • Scalability and policy: BGP is designed to support large routing tables and administrative policy between ASes.
  • Convergence: BGP convergence can be slower than that of many IGPs because of policy, path exploration, timers, and the scale of interdomain routing.
  • Route-flap damping: damping mechanisms can suppress unstable routes in some implementations and designs; it is not a universal default behavior and must be used carefully.
Exam distinction: TCP makes BGP message transport reliable; it does not guarantee that the selected route is optimal for every network, nor does it encrypt the BGP session by itself.

11.2.2 Path Vector Functionality

BGP advertises reachable network prefixes together with path attributes. A receiving router evaluates the routes it learns and applies its BGP decision process and local policy.

AS_PATH

Lists AS numbers the route has traversed. It is a key mechanism for detecting inter-AS routing loops.

NEXT_HOP

Identifies the next-hop address used to reach the advertised destination. The next hop must be resolvable for the route to be usable.

ORIGIN

Indicates how BGP learned the route originally, such as IGP, EGP, or incomplete.

Loop prevention: when a router receives an eBGP route whose AS_PATH already contains its own AS number, it rejects the route to prevent an inter-AS routing loop.

11.2.3 BGP Routing Policies

  • Local policy: an AS chooses which routes to accept, prefer, modify, and advertise based on its operational goals.
  • Best-path advertisement: BGP commonly advertises a selected best path to a neighbor, rather than automatically advertising every path it knows.
  • Hop-by-hop decisions: each AS makes its own routing decisions using the paths and attributes it receives, plus its own policy.
  • Limited control over neighbors: an AS can influence the route information it sends, but it cannot directly dictate how a neighboring AS routes traffic inside its own network.
  • Filtering and safety: prefix filters, AS-path filters, route policies, and maximum-prefix controls can help prevent accidental route leaks and unintended advertisements.
  • Traffic engineering: operators can influence inbound and outbound path choices with BGP attributes and advertisements, but the outcome also depends on policies applied by other ASes.

Policy is local, path selection is distributed

Suppose AS 65010 can reach a destination through AS 65020 or AS 65030. If AS 65020 advertises only its selected best route to AS 65010, AS 65010 cannot choose a different route through AS 65020 that was never advertised to it. It can compare only the candidate routes available to it.

Key takeaways

  • BGP uses TCP port 179.
  • After the initial exchange, BGP normally sends incremental updates.
  • AS_PATH records the inter-AS path and helps prevent loops.
  • NEXT_HOP must be resolvable for a route to be usable.
  • Routing policy is local to each AS; no AS has direct control of a neighbor's internal routing.
  • A router can select only among candidate paths available to it.
